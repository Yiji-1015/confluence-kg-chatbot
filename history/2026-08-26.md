# 2026-08-26 작업일지 — Knowledge Graph 평가 데이터셋

## 1. Person/Document 관계 평가 데이터셋 구축

- Elasticsearch의 문서 메타데이터(`doc_id`, `title`, `author`, `primary_contributor`, `links`, `path`)를 기반으로 Knowledge Graph 평가용 스냅샷 생성기를 작성했다.
- 생성 파일:
  - `ai-server/evaluation/generate_person_dataset.py`
  - `ai-server/evaluation/person_dataset_items.py`
- 데이터셋 ID 형식은 `qa-v3-person-001`부터 시작하며 총 20문항이다.
- 관계 유형:
  - `AUTHORED`: 최초 작성자와 문서의 관계
  - `TOP_CONTRIBUTOR`: 최다 기여자와 문서의 관계
  - `LINKS_TO`: Confluence 문서 간 링크 관계
- 문항 구성:
  - 최초 작성자와 최다 기여자 비교: 8문항
  - 연결된 두 문서의 작성자·최다 기여자 조회: 8문항
  - 연결된 문서 사이의 인물 동일 여부 비교: 4문항
- 각 문항에 `expected_doc_ids`, `expected_entity_ids`, `expected_relations`, `expected_path`, `source_titles`, `snapshot_at` 메타데이터를 포함했다.
- 민감할 가능성이 있는 문서와 유효하지 않은 사용자 값은 생성 대상에서 제외한다.
- `TOP_CONTRIBUTOR`는 재색인 후 바뀔 수 있으므로 데이터셋을 스냅샷으로 관리하고 재생성 시각을 기록한다.

## 2. 인코딩 확인

- PowerShell `Get-Content`에서 한글이 깨져 보여 파일 손상으로 의심했으나, BOM 없는 UTF-8 파일을 PowerShell이 잘못 해석한 표시 문제였다.
- 실제 파일의 UTF-8 내용과 생성된 질문·답변은 정상이며, Unicode replacement character도 없음을 확인했다.

## 3. 검증 결과

- Docker의 `kg-ai-server` 컨테이너에서 생성기를 다시 실행했다.
- Python 문법 검사 통과.
- 총 20문항 생성 및 ID 고유성 검사 통과.
- 문항 분포: `author_vs_top_contributor` 8개, `linked_document_ownership` 8개, `linked_people_comparison` 4개.
- 경로 분포: 1-hop 8개, 2-hop 12개.
- 인물 비교 문항은 동일 인물 2개, 다른 인물 2개로 구성됨을 확인했다.
- 기존 스냅샷과 새 생성 결과는 `snapshot_at`을 제외하고 완전히 동일했다.
