## 코드를 확인하며 정정한 설명

- Context의 3,000자는 청크 추가를 멈추는 기준이다. 문자열을 정확히 3,000자에서 자르지 않는다.
- 문서 재조립은 청크를 이어붙이는 작업이다. overlap 중복 제거와 원본 HTML 복원은 하지 않는다.
- 전체 청크 재조회는 `선택 문서 수 × 50`의 전체 응답 상한이다. 문서마다 50개를 보장하지 않는다.
- 증분 색인 순서는 파싱·청킹 후 기존 청크 삭제, 그 뒤 임베딩·색인이다.
- 삭제 대상은 `ES에 있는 ID - Confluence에 있는 ID`다.
- 외부 링크의 표시 문구는 남지만, 일반 `<a href>` URL을 별도로 보존하는 코드는 없다.
- RRF 점수와 모델 라우팅 규칙은 정답 확률이나 최적 성능의 보증이 아니다.

각 문서의 한계는 코드상 경로를 설명한 것이며, 모든 문제가 실사용에서 발생했다고 뜻하지 않는다.
